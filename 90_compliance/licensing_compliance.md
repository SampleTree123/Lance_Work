## 1. 为什么这是 gating 风险

判定原则：**「模型训练 + 数据集发布」的合法性，取决于每个出现在渲染帧里的资产的许可证。**
"已知改了哪个因子 → 自动生成指令"这套机制**不改变任何许可证义务**——重要的是画面里那些角色/服装/动作/场景/道具/植被各自的授权。

## 3. 安全主路径（推荐）

- 资产来源限定：**CC0** / **自制几何与服装** / **自采或明确授权的 mocap** / 明确授予 ML 训练权的资产 / 必要时**企业授权**。
- **关键技巧（鱼与熊掌）**：人物与服装的**几何**用 CC0/自制，但仍统一**绑到 UE5 Manny/Quinn 骨架** → 保留"共享骨架 = 完美对齐"的全部技术优势（一个 retargeter 驱动所有身份、动作/服装跨身份复用），只是不使用 MetaHuman 等受限资产本身。
- 代价：凑齐 100+ **多样且写实**的人物比直接用 MetaHuman 更费工——这是要权衡的核心成本。

## 4. 未决法律问题（发布前必须由 IP 律师定论）

1. **depicting vs ingesting**：模型训练于"含受限资产的**渲染**"（描绘，而非把资产文件喂进训练）是否构成受限的衍生使用？——这一条同时卡住 MetaHuman 与 NoAI 临界的 Fab 内容；最稳工程答案 = 用 CC0/自制几何从源头绕开。
2. **MetaHuman 5.6 下载版**在 UE EULA + Content Addendum 下，AI 训练限制是否确已随 NoAI 取消？须 **Epic 书面澄清**。
3. **Fab 非 NoAI 资产**："未明文禁" ≠ "已授权"；需法务判断。
4. **取证缺口**：`unrealengine.com/eula/*`、`fab.com/eula`、ActorCore EULA、MetaHuman Content Addendum 调研时 403/证书错误未能逐字取证 → **发布前须归档带日期逐字副本**。
5. **Reallusion 2026-01 许可变更**须在发布前复核。
