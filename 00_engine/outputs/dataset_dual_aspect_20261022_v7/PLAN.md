# 双画幅联合规划

用户已授权实施：整条编辑链含分叉固定横屏或竖屏；两类链数大致接近即可；为新需求适度增加实际渲染视频数量，旧5000/800不是绝对上限。45%—55%是工作参考范围，非用户硬规定。基准为v6 selected_seed1的3752训练、800测试主视频及12000/2400结构链。参考媒体另计。

先尝试保留全部原链，联合分配画幅并最小化跨画幅共享节点数量，比较随机、按共享关系聚类、进一步优化的成本和分布。保留每画幅男女、21种起始镜头、七类编辑支持，避免画幅与内容强绑定。若原链切分成本偏高，再试局部或整体重采样作独立备选，不能把修改过的链称为原链完整保留。

横竖屏是固定拍摄上下文，不新增编辑轴。内容配置与画幅渲染版本分开计数；训练/测试去除画幅后仍不得共享同一内容。参考需求从最终实际使用边重算；动作及背景需求按画幅区分，身份/发型/单件衣物图不因主视频画幅自动翻倍。

所有候选另存。当前仅离线规划：绑定现有双画幅相机模板不表示完成真实场景的视觉验证，也不冻结其旧分辨率、帧率或时长。无UE操作、无媒体渲染。最终交付采用候选、成本取舍、独立检查及正式状态文档的定向同步。
