# 对抗案例审阅

候选：`full_squares_uniform_nodes`。以下11例来自已经采样的真实结构会话；额外合法构造0例单列在 `diagnostic_cases.json`，不计主视频预算。

所有案例均只检查符号状态和继承，未渲染、未视觉验收。中文说明是审阅示意，不冻结训练文本。完整source/target state与父位置见 `ADVERSARIAL_CASES.json`。

## 半身整套换装后改全身镜头

检查半身换整套时，未入镜的下装和鞋也已更新；随后全身镜头必须继承完整目标服装。

来源：`train/session_000142`，5轮，历史节点 `[1296, 1297, 1295, 1297, 1295, 416]`。

- 第1轮从历史位置0继续。整套换装：Hippasuta / Default → Mesh it Up / Default；目标鞋：male.mesh_it_up.asset.d8e8d6907abf。
- 源鞋 `['male.hippasuta.asset.8f98380dc047']`；目标鞋 `['male.mesh_it_up.asset.d8e8d6907abf']`。目标完整core：`['male.mesh_it_up.asset.b637e5071085', 'male.mesh_it_up.asset.bdef73564949']`。
- 第2轮从历史位置1继续。修改镜头：背面上半身 → 正面全身。
