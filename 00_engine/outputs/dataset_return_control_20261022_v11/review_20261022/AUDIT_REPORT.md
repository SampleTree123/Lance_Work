## 4. 合法性、服装和分叉

- 每一步恰好改变一个语义属性；整套服装替换作为一次服装属性编辑处理。其余配置完整继承实际source_position指定的源节点。
- 身份替换限同性且限已允许的四个正面镜头；正面面部禁止动作/服装编辑。发型、发色、场景与镜头的合法组合和用户排除项均核对通过。
- 单件编辑维持同一来源组/搭配组，只改变允许且在该镜头可见的部件，鞋保持。整套编辑跨来源组并完整更新服装，半身镜头也保留完整目标穿搭。
- 鞋不作为独立编辑轴，赤足符合正式白名单。具备单件编辑机会时，单件比例训练47.0116%、测试47.0471%；这是约50%的条件比例，不是所有服装编辑中单件必须占一半。
- 分叉恰好一次且可以发生在最后一步；源历史的完整继承正确，不合并被放弃分支。已接受的回换保留：训练2,003次/1,584条链、测试344次/273条链。完整节点重访为862次/749条链与95次/88条链。

## 5. 训练测试隔离与统计口径

按完整内容配置比较、忽略横竖画幅后，训练测试节点交集为0；没有仅换ID或画幅规避隔离。当前允许人物、服装、动作、场景值及参考池跨split共享，因此可以评价新视频配置上的编辑，不应将结果描述为未见人物或未见场景的独立泛化实验。此项符合已确认选择，不新增holdout要求。

需要准确描述的两个非缺陷现象：初始50/50性别与分叉均匀采样是提议策略，经过约束采样/整链选择后的最终样本不是精确等额。训练起始人物男44.03%、女55.97%，测试男49.42%、女50.58%；人物本身的出现频率范围通过。

六类编辑的±10%要求按整个split核算。单独按画幅看，最大偏差为训练横屏8.41%、竖屏13.45%，测试横屏11.29%、竖屏12.09%；两画幅都有男女、全部21种起始镜头和7种编辑。当前没有约定每画幅单独±10%或全值覆盖，故这些不是失败，也不建议为此重采样。
