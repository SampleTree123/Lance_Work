# v11：降低链内属性回换

当前为离线可审查候选，没有启动UE、渲染或训练。用户批准降低回换偏好；本轮不增加视频节点。

## 实现

沿实际选择的历史源版本追溯属性。新值权重1，刚换掉的值0.05，更早祖先值0.20，其他分支已出现的值0.35。保留属性重复衰减0.4；这些是提议权重，不是最终概率。合法目标的历史偏好也参与属性选择，避免选中仅有A/B的属性后被迫反向修改。

新路径在原图内生成，整链验收保持全量属性和实际编辑目标覆盖、频次范围、单边上限等条件；每条链的不同属性数不低于原链。初始节点、长度、直链/分叉类型、分叉轮次与source_position、画幅全部保留。分叉导致未编辑属性恢复历史源状态，是完整继承语义，不作为回换惩罚。

没有把所有回换禁止，也没有新设统一的“每条链至少修改几种属性”的门槛；保持不低于原链的属性多样性是本轮路径替换条件。优化偏好更少回换，最终分布由图的可达目标和全局约束共同决定。

## 原有要求与成本

主视频仍为训练 5980、测试 1223，合计 7203。
更新后的参考需求为 1609 张图片、809 段动作参考视频（均未渲染）。

节点配置、图边和主视频渲染请求与v10逐字节相同；所有节点仍在链中使用。独立频次、继承语义、实际目标覆盖、源位置绑定、参考链接检查通过。训练完整覆盖和每个动作至少10种有效镜头保持。

## 比较与限制

第一轮虽通过原有检查，但单件服装编辑占合法机会比例下降至约45%，身份编辑数下降约5%。因此选第二轮：单件比例限制47%–53%，身份次数相对v10偏移最多2%，其他各属性次数偏移最多5%，六类总体仍满足均值±10%。这些是本轮保护既有混合比例的实现条件，不是新增用户硬性数据契约。

回换不为零；剩余回换集中在较长链。隐式分叉恢复可能增加，意味着被放弃分支与历史源的差异更大，不等同于新增显式回换。没有证明全局最优或多随机种子稳定性。旧v10及试验均保留，未覆写旧结果。
