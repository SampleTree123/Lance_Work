# 第二次节点与链联合构造：结果与下一步

2026-10-21。已执行两条改进路线，并由独立脚本检查保存的节点、边和历史引用。**回访过多的原因已定位，但本轮仍没有同时满足节点预算、链数及完整抽样要求的候选。** 本次没有修改 UE、资产、已确认规则或视频预算，也没有渲染。

## 最重要的发现

旧方法先形成有限图，再从已有邻边选编辑。刚到达一个新节点时，返回上一个节点的边往往已经存在，而其他目标不存在，于是本应普通的回退变成主要选择。例如，选中与父节点入边相同的发色属性时，旧训练候选有88.2%的编辑返回入边起点，完整七色域的对应概率应为1/6。这不是“允许自然回访”本身的问题，而是构造方式放大了它。

本次先按正式合法域选属性和服装模式，尝试在需要时增加目标节点。为控制回访，还按完整目录中历史目标所占概率选择是否回到历史状态。此改法将保存训练链的完整状态回访率降到4.48%，但大量长链因找不到预算内目标而无法完成。失败后换起点重试，也仍然改变最终接受样本的分布。

## 实测对照

以下是不同构造结果，样本数及长度组成不同，不能当作控制变量完全相同的效果比较。

| 路线 | 训练池节点 / 完整唯一链 | 测试池节点 / 完整唯一链 | 训练链完整状态回访 |
| --- | ---: | ---: | ---: |
| v1有限图诊断代表 | 2,500 / 12,000 | 500 / 2,400 | 69.95% |
| 本轮预算内联合构造 | 2,500 / 1,897 | 500 / 242 | 4.48% |
| 本轮全域抽样预算前缀 | 2,499 / 699 | 499 / 122 | 不与较大诊断样本混报 |

预算内联合构造实际引用训练1,923节点、测试358节点，剩余节点是未被完整链使用的构造结果，不能算有效视频交付。训练链缺10,103，测试链缺2,158；接受结果偏向短链，长度及直链/分叉配额未满。保存链保持原子编辑、合法服装、完整历史继承和跨集合完整节点不重合。

另一条对照复用40个初始根，但每次编辑都从完整合法目录抽取；不因已有边缺失重抽属性。它的12,000次训练链抽样需要30,544个唯一节点，其中有3条重复结构，即11,997条唯一链；2,400次测试抽样需要7,536节点。训练自然回访3.56%，服装两种模式均合法时单件占50.80%，各属性实际次数与源状态条件期望之比为0.994–1.010。**这是这一种路线的实际成本，不是最低节点数，也不证明当前预算不可能实现。** 这组较大诊断只有汇总与预算内前缀交付，不能误当作已保存的完整正式图。测试禁入集合为实际预算训练节点，较大训练诊断不是另一个已冻结split。

## 独立检查的结论

- 两条保存路线的单属性变化、服装合法性、历史出现位置、完整父状态继承、结构去重及训练测试节点隔离通过；链数和配额不足单列，没有把不足掩盖为完成。
- 联合构造的回访概率计算本身与独立计算相符，但“失败就换起点再试”使接受结果仍偏斜。例如训练发色回到历史完整节点31次，依据真实源条件累计期望为14.83次。低整体回访率不等于条件抽样已达标。
- 完整域对照的编辑抽样更接近期望，但40个固定初始根使起始发型、服装等支持有限、互相关联；不能声称初始组合已充分均匀。
- 分叉仍允许自然产生“从最新源也能得到相同结果”的例子。本轮联合构造为训练57/474、测试4/52；没有新增强制过滤。因为接受样本的长度分布改变，不能把下降全部归功于分叉改善。
- 诊断残差只用于找偏差。多条链共享节点，不满足独立样本假设，不提供伪精确p值。没有进行视觉或训练效果验证。

## 下一步建议

不建议继续靠重抽和权重补偿把缺额凑满，也不建议直接把预算提高到上面的三万节点。应先讨论“均匀抽样”的实际要求：是要求每个源节点都能按完整目录概率选目标，还是允许局部候选有限、但在整个数据集中平衡覆盖目标值和编辑任务。

如果可以采用后者，下一条值得尝试的路线是按编辑扩展若干可交叉组合的小图，跨小图平衡人物、镜头、服装等，再从中形成多种历史路径；保持每条边单属性、服装正式规则、完整历史继承与节点去重。小图内候选范围会改变，**这只是建议，尚未替用户决定或实施**。如果继续坚持当前完整域条件概率解释，则先研究更有效的节点共享，或者讨论链数/节点数取舍。当前规则继续有效。
