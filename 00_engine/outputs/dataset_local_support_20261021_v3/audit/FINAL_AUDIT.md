# 冻结候选独立核验

当前冻结候选为 `linked_complete`。独立结构检查通过，训练/测试全部2,500/500节点都在实际12,000/2,400条链中使用，实际使用13,922/1,767条边；训练测试完整状态重合0。硬检查复用v1独立核验器及正式服装解析，不导入本轮生成器。

两组实际已用节点均覆盖全部40身份、33发型、37服装family、45合法group、7发色、25动作、21镜头和21场景。此前的group及九龙点位缺项已补齐。这里的类别覆盖不等于所有衣物单件、鞋和跨属性搭配都齐全。

与v1均匀起点代表相比，训练身份编辑方向从210增至427种，测试从114降至77种；训练发型/动作/镜头/场景方向分别186/220/184/194种，低于v1的340/410/340/337种。训练每款女性发型关联身份/服装family/场景的中位数为6/5/4.5，男性9/9/7，也低于v1的7/7/10和10/15/15。测试部分服装与搭配指标改善。不同维度存在取舍，不能宣称整体多样性验收通过。

四身份镜头起点占比为训练31.92%、测试30.08%，全目录平衡目标26.09%。按实际源视频的正式合法属性权重计算，全局属性比例总变差5.62%/4.46%，v1为3.43%/8.59%。正式可选单件时，实际选择单件49.21%/47.50%，目标50%。这些结果仍不证明每个源视频的条件概率完全一致。

包含完整旧视频回访的链为48.27%/66.96%，v1为69.95%/67.83%；以编辑步为分母，回访为18.01%/29.13%。整链只在一对视频之间编辑的比例为6.12%/13.96%，同一对视频正反方向合计至少经过3次的链为8.17%/19.42%。测试仍有明显重复，不能因训练改善而忽略。

分叉历史源完整状态与最新视频不同的比例为93.95%/92.75%。若进一步检查“未编辑部分继承的内容是否不同”，比例为63.55%/47.25%，v1为56.12%/55.62%。因此测试中仍有较多分叉未形成这种额外继承差异。自然回访、单属性链、末轮分叉和重复经过同一边均为已允许行为，以上只作为指标，不新增硬禁令。

单件资产及共享鞋仍只覆盖部分目录：训练女性服装family内资产88/131、男性125/157；测试81/131、115/157。共享鞋训练女性9/9、男性9/22；测试女性9/9、男性4/22。实际全目录缺项、各发型搭配、节点/边热门占比和各编辑方向保存在机器报告。
