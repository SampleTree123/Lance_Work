# 当前linked候选独立核验

本报告只评价 `dataset_local_support_20261021_v3/linked`，对照为 `balanced_camera` 与上一轮代表 `dataset_trial_build_20261021_v1/full_squares_uniform_nodes`。此前 `AUDIT_NOTES.md` 针对旧dense候选，不代表当前结果。少量对照数字见 [COMPARISON_LINKED.md](./COMPARISON_LINKED.md)，完整独立证据见 [verification_linked.json](./verification_linked.json)。本轮不将候选晋升为正式数据。

## 已完成的结构核验

- 训练2,500个节点、12,000条结构链；测试500个节点、2,400条结构链。所有节点在实际链中出现。实际使用边为13,973/1,779条，候选图边为17,436/1,864条。
- 历史选源完整继承、单属性边、服装及鞋的正式合法性、恰好一次分叉、长度与链型配额、完整配置去重通过。训练测试完整状态重合0。硬检查复用v1独立核验器，未导入本轮生成器。

## 本次修正的实际效果

1. 四个身份镜头在起点中的占比为训练32.19%、测试29.21%，已接近正式全目录平衡目标26.09%，仍分别高6.10和3.12个百分点。镜头平衡前dense候选的57.58%/73.92%不再代表当前结果。
2. 训练身份编辑占8.9018%，按本次实际源视频的正式合法属性计算，期望8.9053%，基本接近。测试实际9.7146%，正式期望8.1735%，仍高1.54个百分点。全局属性比例总变差为5.76%/4.38%；镜头平衡版为9.49%/4.95%，v1为3.43%/8.59%。
3. 正式可选单件时，实际单件替换占训练49.18%、测试48.41%，目标50%。整体衣物模式总变差0.64%/1.21%。这些是全局结果，不证明每个源视频的选择概率都精确相同。
4. 身份方向从镜头平衡版的20/20种增至438/78种，v1为210/114种。训练身份方向明显增加，测试尚低于v1。为此训练发型/动作/镜头/场景方向减少至186/220/184/193种，v1为340/410/340/337种；测试发型92、镜头88、场景76种，也低于v1的171/125/89种。不能将身份改善表述为全维度多样性提高。

## 分叉和单边来回的实际情况

- 包含完整旧视频回访的链：训练5,773/12,000=48.11%，测试1,587/2,400=66.13%。以编辑步为分母，回访为7,826/43,800=17.87%和2,558/8,760=29.20%。两种比例含义不同。
- 分叉源完整状态与最新视频不同：训练3,776/4,000=94.40%，测试712/800=89.00%。进一步要求“所编辑属性以外的继承内容不同”，比例为64.90%/46.62%；v1为56.12%/55.62%。所以部分分叉虽然历史位置不同，实际继承差异仍不明显，测试更突出。
- 整链只在一对完整视频之间编辑：训练699/12,000=5.83%，测试329/2,400=13.71%。同一对视频正反方向合计至少经过3次的链为950/12,000=7.92%、480/2,400=20.00%。单属性整链14.89%/24.58%。
- 自然回访、单属性链、末轮分叉和重复经过同一边都是已允许行为，以上仅描述实际训练信息的组成，不作为新硬禁令或自动失败条件。
