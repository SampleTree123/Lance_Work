# 第三版独立核验结论

本轮核验对象是 `balanced_dense`，对照为同图 `blocks/dense_diverse` 与上一轮代表 `dataset_trial_build_20261021_v1/full_squares_uniform_nodes`。完整数字见 [COMPARISON.md](./COMPARISON.md)；机器证据见同目录三个对应 `verification_*.json`。核验器未导入任何本轮生成器，硬结构与服装合法性复用早先独立核验器及正式衣物解析。

## 已确认

- 第三版两套采样均满足2,500/500候选节点与12,000/2,400实际结构链；全部节点在实际链中出现。单属性边、历史选源完整继承、单次分叉、长度与链型配额、衣物合法性和完整状态去重通过。训练/测试完整状态重合0。
- `balanced_dense` 与 `blocks/dense_diverse` 的训练和测试 `nodes.json` / `edges.json` 哈希分别完全相同，因此它们确实共用同一候选图。两者起点分布也发生变化，比较显示的是整体采样策略效果，不能只归因于属性补偿一个因素。
- 相对同图无补偿采样，全局属性比例总变差由训练18.86%降至11.12%，测试13.31%降至6.15%。正式允许单件替换时，实际单件选择为训练3,060/6,079=50.34%，测试583/1,165=50.04%，接近已确认50%目标。

## 仍然存在的问题

1. **起点镜头明显偏向可换身份的四类镜头。** 正式全目录权重为四类各1.5，其余17类各1，合计目标6/23=26.09%；第三版补偿后实际仍为训练57.58%、测试73.92%。上一版代表为27.39%/30.63%。局部合法支持的确认没有取消这个平衡目标。
2. **训练身份编辑比例不足。** 按实际选中的源视频及正式合法属性计算，身份编辑应占16.54%，实际5.42%，少11.12个百分点。训练1,734个正式可换身份的源节点中，仅98个被安排身份出边；测试416个中仅90个。有限支持本身不判失败，但这个分配缺口会形成实际属性偏差。第三版全局比例仍不能称为正式权重精确实现。
3. **方向多样性有明显取舍。** 第三版身份方向训练/测试均只有80种，上版代表为210/114种；训练发型、动作、镜头、场景方向分别250/240/181/250，上版为340/410/340/337。第三版单件衣物方向174/86种优于上版121/36种，测试跨family整套方向119种优于上版59种。不能把某几类提升概括为整体多样性通过。
4. **跨属性搭配的训练覆盖下降。** 每款女性发型关联身份/服装family/场景的中位数为4/6/5，上版为7/7/10；男性为7/10/12，上版为10/15/15。测试女性关联身份中位数由2提升至3、男性关联family由3提升至4。每款发型的细项、最少值和缺失见JSON。
5. **回访仍较多，测试有退步。** 第三版完整旧节点回访占训练20.45%、测试32.42%；上版为31.03%/30.03%。单属性整链为16.87%/26.79%，上版17.78%/17.75%。这些属于已允许的自然现象，不设置硬禁令；这里如实展示它们的实际占比。
6. **标签覆盖不能替代实际多样性。** 已用节点包含全部身份、发型、发色、服装family、动作、镜头和场景标签，但训练仍缺3个合法服装group，测试缺2个；测试发色方向仅38/42。上述方向和搭配差异仍存在，不能仅凭标签齐全宣称多样性验收通过。

## 范围与解释

“硬结构通过”只表示本轮保存的离线节点、边、链符合这些结构和语义条件，不代表媒体交付成功、画面正确或采样质量已经验收。未渲染、未核验视觉效果、未修改正式配置或旧快照。局部目标数量、分布偏差、方向覆盖和回访均作为描述指标，不擅自引入新硬阈值。方向基线和全部节点/边引用集中程度保存在对应JSON。
