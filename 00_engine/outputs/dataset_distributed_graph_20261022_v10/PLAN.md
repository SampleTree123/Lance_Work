# 第十轮：从生成阶段分配多样性的构图

2026-10-22 用户已恢复执行。所有工作限离线配置、链条和参考需求；不操作UE、不渲染、不训练。此前v9补齐动作镜头的候选未获接受，保留作比较，不作为新构图的主体。

## 已确认规则

- 训练12,000条链、测试2,400条链，2–5次编辑，直链与一次回溯链约2:1，原长度配额和历史源完整继承保持。
- 训练覆盖全部合法目录值。测试仍不要求全目录覆盖；两分区忽略横竖屏后完整内容状态不重合。
- 各人物、动作、发型、发色、场景、可见核心衣物的出现次数，以各维度平均值的0.5–1.5倍为平衡目标。分别检查实际用到的不同内容配置和最终链的完整历史位置出现次数，横竖屏副本不充作内容多样性。
- 每个训练动作至少10种合法镜头，且该动作在所采用镜头中的频率也在自身均值的0.5–1.5倍范围。
- 每件训练核心衣物至少3个动作、3种有效镜头；不要求完整3×3组合。人物随机合法搭配，不要求一件衣物跨固定数量人物。服装计数优先，动作/镜头分散其次。
- 衣物可见性用已存在正式镜头/服装规则：面部近景不计，半身取正式upper与core资产交集，其他镜头取core；这不是像素遮挡检查。
- 起始镜头四种身份编辑镜头权重1.5，其余1；合法场景排除与所有服装单件/整套规则保持。
- 历史重复属性权重衰减0.4；六种非身份编辑次数偏差不超过各自均值10%；平均有向内容边复用约2.5为软目标，单边最多4次，第四次尽量稀少。
- 整条链及其全部分支固定一个画幅，横竖屏链数大体接近。以实际需要的视频数衡量成本，参照v8的6,439，不能以旧允许上限替代真实增幅。

## 实现与验收

1. 从属性值和组合欠额出发建立普通可编辑局部网络；每件衣物直接进入动作、镜头及其他轴可继续编辑的上下文，不最后补单节点充数。
2. 优先复用合法相同终点、交叉编辑路径和多轴邻居，在预算内增加连接。
3. 抽链时使用频率反馈，保持所有历史/原子编辑规则；链中的实际频率必须重新核算，不能拿图的频率代替。
4. 独立检查实际使用节点与完整链，逐值输出上下文和频率。若存在目标偏差，保留具体失败和原因，不把旧覆盖率当新规则通过。
5. 结构达到新规则后再分配画幅、生成参考需求和请求，比较实际视频成本；同步当前候选、方法、证据和限定状态。
