# 能推翻假设的泛化实验与消融

2026-10-21。只读实际 21 个有效场景及第一轮 main 图；不加载 UE、不改原 run，没有训练或渲染。这里给的是可执行的子集/对照设计，不是任何模型性能结论。生成代码与精确节点/边/session 清单见同目录 JSON。

## 1. “新场景”需要先分清三个问题

随机留 5 个 scene ID，可以评价选定实例留出，但不保证新类型留出，也不保证同类型新实例。当前第一轮其实取 catalog 前 16/后 5，并非随机；`category=primary` 是“主场景”的用途分类，不是街道/沙漠等语义类别。

下表仅依据现有名称/包名提出分组假设，尚未核对视觉、共享资产族或当前站位画面。必须在看模型结果之前人工确认粒度；无法确认的场景保留 uncertain，不凭名称当视觉 GT。

| 暂定粗类 | 实际场景 | 当前 train/test 场景数 |
| --- | --- | --- |
| 未来/风格化城市 | 赛博朋克城市、未来都市、合成波城市 | 2 / 1 |
| 东亚传统建筑环境 | 中式建筑、樱花庭院、日式村落、京都小巷 | 4 / 0 |
| 东亚现代街区 | 香港街道、九龙巷道、日本城市街区 | 2 / 1 |
| 欧洲历史建筑环境 | 中世纪城堡、维多利亚街道 | 1 / 1 |
| 干旱自然地貌 | 沙丘、红色沙漠 | 2 / 0 |
| 交通设施 | 沙漠加油站、傍晚公路、停车场、地铁站 | 3 / 1 |
| 海滨小镇 | 海滨小镇 | 0 / 1 |
| 游乐园 | 游乐园 | 1 / 0 |
| 末日城市 | 末日城市 | 1 / 0 |

粗类下，当前测试的合成波城市、日本城市街区、维多利亚街道和地铁站都有训练同粗类，海滨小镇没有。但细分后，地下地铁与户外公路的差异可能比两个“城市”更大；中世纪城堡与维多利亚街道也不是严格相同类型。这不是任选标签都能得出同样结论的划分。

在这套暂定 9 类上穷举全部 **20,349** 种留 5 场景方案：7,228 种没有整类缺席，13,121 种至少含一个训练中完全缺席的粗类。随机留 5 因而约 64.48% 会混入粗新类型，主要还受到三个单例类影响；这一数值只说明随机留出会混合问题，随分组改变而改变，不是客观数据难度。

建议分别报告：①seen-type/new-instance；②new-type/new-instance；③无法可靠归类。对于海滨等单例，类型与场景实例、特定资产包风格完全混杂，不能单凭这一例推断“掌握了新类别泛化”。可以先保留为强分布变化案例，再在以后补同类多实例时检验。

“seen instance × unseen type”的完整 2×2 在语义上不成立：训练见过这个实例，就见过它所属类型。不能画一个四格表并编出第四格。下面改用可实现的训练暴露干预 × 固定测试队列 2×2。

## 2. 不补 GT 节点的最小 2×2

### 2.1 两个训练条件、两个测试队列

选择暂定“未来城市”类型作受控暴露：

- A−：合成训练不含赛博朋克/未来都市/合成波类型；加入一个非未来类型的匹配 donor 模块。
- A+：其余训练完全相同，用同非 scene 状态、同轴、同目标值的未来类型模块替换 donor 模块。
- 测试 T：从未用于两条件训练的合成波城市。
- 测试 U：从未用于两条件训练的日本城市街区，作为不受未来类型训练暴露直接改变的控制队列。

|  | 固定 T：合成波城市 | 固定 U：日本城市街区 |
| --- | --- | --- |
| A−：合成未来类型未暴露 | Y−T | Y−U |
| A+：合成未来类型已暴露 | Y+T | Y+U |

比较 ΔT=Y+T−Y−T、ΔU=Y+U−Y−U，以及 ΔT−ΔU。若两个队列同幅改善，证据更接近通用编辑收益，不能专称“同类场景暴露帮助新场景”；若 ΔT≤0，则本次“同类训练会有帮助”的假设被直接挑战。差中之差仅是有明确对照的有限实验，不凭两个非随机场景宣称总体因果效应或 parallel-trends 已成立。

### 2.2 精确已有支持，不是每池平均分

训练图中，**赛博朋克城市 vs 樱花庭院** 有 78 对完全匹配的非 scene 有向边，实际为 39 对正反方向边；每个模块 **30 节点**，覆盖相同的 4 身份、6 动作、5 相机、3 发色。每对除 scene 外的 source/target 全字段一致，因此编辑轴和新值分布严格匹配。

共同 base 排除所有未来类型场景、两个模块的端点，并排除 3 个因此变孤立、没有监督边的节点后，实际有 **2,236 节点、10,384 有向边**。A+/A− 分别加未来/樱花模块后，各 **2,266 个有监督视频节点、10,462 条选择的有向边**。两边真实视频集合 R 必须相同，base 与模块采样权重、原子监督次数、训练步数也相同。这个实验使用原 2,500 训练池的子集，不为凑 2,500 增加新视频。

测试图中，**合成波城市 vs 日本城市街区** 有 26 对完全匹配的非 scene 有向边，实际为 13 对正反边，仅需要 **11+11 个已有节点**。单轮筛查是两个训练条件 × 两个测试队列 × 26 次编辑 = **104 次模型编辑调用**；相对既定主池，GT 视频节点需求为零新增。**节点已存在不等于视频已经渲染；实际运行仍需相应主池媒体与模型可用。**四格重复使用同一 test，不是四份独立测试集。

匹配标准包括 source 与 target 的 identity/action/camera/aspect/hair_color，唯一差别是 scene；因此比从两场景随便各挑相同数量视频更能隔离场景条件。仍不保证实际成片的尺度、遮挡、背景复杂度相同；这些正是场景干预的一部分，应记录而不伪称视觉完全匹配。

### 2.3 能做小多轮对照，但有明确容量上限

共同 test 子图穷举得到 strict source 可归因、无重复 state、至少两编辑轴、fork 后有继续编辑的路径：linear 长度 2/3/4/5 共 44/88/108/108；fork 长度 3/4/5 共 78/298/618。可选择每队列 **60 个完全对应 session**：40 linear（每长度 10），20 fork（4/8/8），根/中间源为 8/12，满足 2:1 与 20%/40%/40%、40%/60%。两个模型 × 两个队列共 240 次 rollout、896 次编辑调用。

但 11 节点共同子图分成 **9 节点多轴组件与 2 节点单轴组件**。这 60 个 session 每队列只用 9 节点，实际仅 **2 身份、3 动作、2 相机、2 发色**；另外两身份处于单轴双节点组件，结构上无法同时满足无重复状态、长度≥2、至少两轴的多轮要求。不能把单轮模块的“4 身份覆盖”搬到多轮表里。

这组 18 视频的 60 对多轮轨迹是低成本反证/校验实验，不能扩写为充分的场景或人物泛化 benchmark。若结果差，能推翻局部假设；若结果好，还不足以证明广泛稳健。所有选中节点、父 occurrence 和路径在 `minimal_scene_exposure_2x2.json`，原 run 未改。

### 2.4 必须限定“未暴露”的范围

A− 只保证**本项目合成训练没有未来场景类型**。真实单轮训练数据可能已有赛博城市、人物替换、服装、动作、镜头等；底座预训练也未知。未审计全部真实训练时，不能把 A− 写成“模型没见过未来类型”，更不能叫“未见编辑任务”。默认报告 `synthetic_finetuning_type_exposure` 与 `dataset_scene_id_holdout`；整类任务未见需要在所有显式微调来源中排除该类和等价监督，并声明预训练未知。

## 3. 把多轮收益与数据增量混杂分开

最直接、已经有现成数据支持的核心对照：从同一个 session 清单产生两种训练视图，**唯一视频、唯一原子边、逐次监督目标和目标出现次数完全相同**。

第一轮实际 main train 的 12,000 session 共 **44,800 个编辑监督位置**，引用 2,500 唯一节点、实际使用 **10,104 条不同有向边**。注意图中 11,800 条登记边不是都进入训练，不能用登记数代替监督边数。

| 训练臂 | 合成视觉/端点池 | 原子监督记录 | 历史输入/语言 | 用来检验 |
| --- | --- | --- | --- | --- |
| F：原子展开 | 相同 2,500 视频 | 相同 44,800 turn、10,104 unique edges | 给正确 source + 合法独立指令 | 单轮编辑和更多合成数据本身 |
| H：连贯历史 | 同 F | 与 F 一一相同的 target/loss 位置 | 只给合法过去，按 dialogue 解析历史 source | 历史组织/指代监督的增量 |
| P：输入量对照，可选 | 同 F | 与 F 同一批记录 | 独立指令与正确 source；等长无关/重复上下文，保证任务仍可解 | 额外输入量/上下文格式是否已解释收益 |

F 不能直接喂“回到第二版”却不给历史；必须由真实边展开独立指令，否则比较的是输入被破坏。H 不能偷给 hidden parent；若为了固定 source 编辑诊断而给 parent，必须所有相关臂一致，并把自主选源测试另列。P 的无关上下文不能改掉用户指代含义或制造多解；它是输入量控制，不是“随机打乱必然有正确标签”的伪任务。

**等唯一视频不等总视频读取量。**若 H 在第 t 轮给全部 t 个历史视频，按当前长度配额共 112,800 次历史视频引用，而 F 是 44,800 次源视频引用。两者唯一节点同为 2,500，GT target 同为 44,800，但输入像素/token/FLOPs 不同。应同时记录唯一视频数、输入帧/token数、原子 target 数、optimizer updates、总计算；不能只说“等步数所以算力公平”。P 可匹配每个 loss 位置的帧槽数量，或另做匹配总计算预算的敏感性，但不要削掉 H 必要证据来凑公平。

### 3.1 再加一个 2×2：历史组织 × 边多样性

更完整的四臂是 H0/H1 × Dlow/Dhigh，真实数据 R 在四臂完全相同：

|  | Dlow：较少 unique edges、更多重复 | Dhigh：更多 unique edges、较少重复 |
| --- | --- | --- |
| H0：原子展开 F | F-low | F-high |
| H1：连贯历史 H | H-low | H-high |

四臂固定 2,500 个唯一合成视频、44,800 个 target 呈现位置、同一 optimizer update/batch 定义与真实 R；在每个 D 内，H/F 使用相同有序 target 记录多重集。Dhigh 可用已实现的 10,104 条监督边；Dlow 暂可目标 7,578 条（75%），但**必须先验证覆盖全部节点、可形成同长度/fork 配额且 source 可归因**，未生成前不声称其容量成立。

比较 H-high−F-high 与 H-low−F-low 才较接近历史组织增量；比较 F-high−F-low 检查“更多不同边”本身是否解释提升；差中之差检验历史收益是否依赖边丰富度。若只有增加 unique edges 能提升，而同边的 H/F 无差异，多轮历史是收益来源的假设就被挑战。

在只有两模型预算时，先做实际已可兑现的同 Q 的 F/H；在四模型预算时做上述 factorial；P 输入量对照和 R-only 可作为后续。不是为了一个大矩阵强行扩大第一轮生产。

### 3.2 真实 + 合成的域混杂

R-only vs R+H 若改善，至少同时变化了合成视觉域、视频数量、边数量、历史输入和训练监督，不能单称“多轮训练有效”。首先加入 R+F；若 R+F 与 R+H 同幅改善，多轮特有收益缺乏证据。

R-only 的等步数对照可在合成位置重复采 R，但其真实数据重复次数改变；R+F/H 四臂应固定相同 R 呈现次数。若再做 real-flat vs synthetic-flat 等数量/等边计数对照，媒体内容本来就不同，不可能同时“完全相同视频”；它只能检验选定匹配样本下的域/来源差异，不能把计数匹配当成内容匹配。

测试也要分本项目合成域与独立真实域。没有真实多轮分支测试，就不能从合成历史任务得分改善推断真实视频交互收益；可以先在真实单轮上检验是否只是单轮质量改善或是否出现负迁移。真实数据内容/数量目前未读取，不在 JSON 编造规模或类别覆盖。

## 4. 哪些结果会推翻我们现在的解释

1. 同边同节点同监督次数下 H 不优于 F，或者两者只在单轮质量上同幅改善：不足以将收益归因于历史学习。
2. history-necessity 成对探针中，删掉必要历史后仍能两边都对：先查当前指令是否泄漏完整旧值、文件名/pair ID、总长度或目标参考泄漏，再考虑科学解释。
3. 加入无关弃支改变目标结果：whole-parent 继承假设没有得到行为支持，即使平均单轮编辑分数好看。
4. 未来类型训练暴露对 T 与 U 的改善相同，或目标 T 不改善：不能宣称同类型训练帮助该新场景；单例 T 好也不能证明任意新类型泛化。
5. 只在 m=1 回退得分高，在 m≥2、lag 较大或非 root 情况失败：结论应收敛到回退与内容继承，不写成稳健的多候选历史推理。
6. nominal 路径分数上升却实际 source 的非目标内容被偷偷修复/覆盖：累计目标正确与当轮遵从不是同一件事，两个指标须同时报告。

本轮输出是用于选择下一步实验的最小反证设计。脚本验证了精确状态/边匹配与选中路径，未验证自然语言充分性、实际视频可观察性、真实数据覆盖、模型训练效果或统计功效。
