# 配置不同，不一定形成可学习的视觉编辑

2026-10-21，离线研究。读取现有正式 production10 的相机轨迹与代表人物骨骼，不加载 UE，不重新审查用户已接受的场景。这一目录提出数据契约和取样建议，不修改任何拍摄点。

## 1. 新发现：动作边保留的是镜头规则，未必是同一条相机轨迹

现有 25 个有效动作、21 个镜头、两种画幅，共 1,050 条轨迹。按全段相机位移不超过 1cm、视向变化不超过 0.1°、视野角变化不超过 0.01° 的近似静止定义，静止数为零。

“正面全身”确实保持固定视向，但会跟随人物。每段最大离开初始位置的距离，在 25 个动作中位数为 14.58cm，最大 450.20cm。这不是镜头故障，而是已经设计的跟拍行为。

更重要的是，在同一个“正面全身”规则下比较 25 个动作的 300 对组合：

- 相机位置差异的逐段最大值，中位数为 101.07cm。
- 消除两个镜头的初始位置差后，轨迹差异最大值的中位数仍为 96.64cm。
- 300 对中没有一对的全段轨迹差在 1cm 内；35 对在 10cm 内。
- 视向角度差均为零。

这些数值来自实际相机键，不是模型实验。完整 12,600 个动作对 × 镜头/画幅的比较见 [camera_action_coupling.json](./camera_action_coupling.json)。

**建议沿用“保留镜头规则”作为这批动作编辑的主契约。**例如“动作改为参考中的动作，保持正面全身跟拍”，允许相机按照相同跟拍规则响应新动作。不要同时在文字里承诺“背景每一帧完全不动、原相机轨迹逐帧不变”，又用现有自适应轨迹作为真值。

如果以后确实研究严格固定相机路径的动作替换，应单独给定绝对轨迹，并检查新动作是否离开画面；那是不同的拍摄计划。当前没有必要为这个研究方向重做已经验收的相机。

## 2. “一个属性”应落实为一个干预，加上明确的派生规则

适合当前系统的关系是：

```text
动作 ─→ 身体轨迹 ─→ 固定规则下的跟拍路径
服装 ─→ 轮廓、遮挡、阴影
场景 ─→ 场景光源和用户保存的曝光
发型资产 + 原色选项 ─→ 资产自己的颜色
```

前两项通常是合理派生变化；最后一项会影响“只改形状”的解释。镜头、灯光与其他属性的像素不变不能作为所有编辑的统一验收标准。建议记录 `requested_axis` 与 `allowed_derived_effects`，先按语义判断单属性，再使用与该边匹配的画面指标。

这与可控合成数据保存场景参数、相机和丰富真值的思路一致，但不能因为有参数就认定模型可从画面识别它。[Kubric，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/html/Greff_Kubric_A_Scalable_Dataset_Generator_CVPR_2022_paper.html)

## 4. 三种状态分开，能同时解决浪费与错误监督

1. **配置状态**：引擎中完整衣服、鞋、发型等参数，即使在镜头外仍存在。
2. **当前可观察状态**：本段视频实际可辨认的内容。配置不同可能得到几乎相同的视频。
3. **历史可知状态**：当前镜头看不到，但以前的视频或明确指令已经给出。

例子：先换鞋，再切到头部近景，最后回到全身。鞋仍应按所选版本继承。近景不需要重新显露鞋；但是在近景这一步要求“换鞋”并用两段几乎相同的视频教模型，监督价值很低。若以后专门研究不可见属性记忆，应明确作为隐状态任务，并给出历史证据，不能假装普通视觉编辑。

这里也不建议将镜头外配置无条件丢弃：它会影响以后镜头的结果。可以让“语义节点”保留完整状态，而“媒体节点”按实际渲染等价关系复用；正式使用前需要像素/资产依赖证据，不能只凭骨骼框宣称两段媒体完全相同。

## 5. 少量高价值后续，不扩大为全资产重审

建议从现有候选中选三类小样：

- 明确可见：正面/侧面中景的换发型、换上衣，作为正常例。
- 临界可见：头部小、侧背面、短暂露出目标部位，确认阈值敏感性。
- 明确弱证据：近景换裤子，作为取样器应回避的例。

先完成渲染小样后再决定取样过滤，不提前把 64px、50% 时长等代理阈值定成正式规则。主任务不需要这些弱证据边来凑链数：图实验已经表明结构容量充足。

## 6. 重现与边界

运行本目录三个脚本：

```powershell
python analyze_camera_observability.py
python analyze_camera_action_coupling.py
python analyze_semantic_visibility.py
```

仅依赖标准库和项目已有的离线投影函数。骨骼是 planner 的代表性别，非 40 人实测；人体框为粗略包围，未模拟头部真实朝向、头发/衣物轮廓、场景遮挡、阴影或曝光。时点是稀疏样本，不覆盖两帧之间的所有行为。相机轨迹比较也未包含运行时地面跟随。所有数字是诊断证据，不能写作媒体已经通过。
