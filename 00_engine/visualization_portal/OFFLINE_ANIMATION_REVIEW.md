# P0 动画离线审查

## 启动

双击 `OPEN_OFFLINE_ANIMATION_REVIEW.cmd`。页面只访问本机
`127.0.0.1`，不需要互联网。

如果浏览器没有自动打开，访问：

`http://127.0.0.1:8765/00_engine/visualization_portal/#/runs/2026-08-18-cc-animation-p0-offline-review-v1`

## 每条动作需要填写

1. 决定：接受、淘汰、暂缓或保持未审查。
2. 自然度：1 到 5。
3. 动作语义：待机、移动、手势、运动、过渡、交互或其他。
4. 性别倾向：偏女性、偏男性、通用或不确定。
5. 道具依赖：无道具、单手、双手、家具/支撑物、另一人物或疑似依赖。
6. 备注：记录不自然、接触错误、适用情境或淘汰原因。

页面会自动将进度保存在当前浏览器。建议每完成一段就点击“导出决定”，
得到 `cc_p0_animation_remaining_69_review_decisions.json`。这是跨浏览器、跨电脑和故障恢复的正式交接文件。

## 离线边界

- 可以关闭 CC、UE 和 Codex；只需要保留本目录以及页面引用的本地产物。
- 不要使用浏览器隐私模式，否则本地自动保存可能在关闭窗口后被清除。
- Root Motion、骨骼、面部通道和隐藏对象由自动化结果提供，不需要人工填写。
- 本轮决定只是候选筛选，不直接授予生产资产状态。
