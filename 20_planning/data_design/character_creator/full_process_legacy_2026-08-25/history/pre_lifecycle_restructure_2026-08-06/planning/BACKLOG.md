## P2：真实度与身份质量

| 项目 | 当前判断 |
| --- | --- |
| 更高分辨率皮肤纹理 | 可能比继续调全局材质参数收益更高；需要同条件 A/B |
| 身份局部不对称 | 有助于减少合成人脸感，但必须避开眼口支撑参数 |
| Facial Profile/动态皱纹个体化 | 当前统一档案够用；身份质量稳定后再分组 |
| 耳朵、鼻翼、眼睑和唇部次级结构 | 应以高质量 seed 为主，局部 Morph 为辅 |
| 泪线与眼部湿润精修 | 5A 未把所有候选参数纳入生产；需多灯光回归 |
| 牙齿与口腔材质 | 当前几何可用；特写和张嘴镜头需要专项比较 |
| 面部微表情库 | 动态真实度高价值；先扩大安全面部 clip，再考虑随机微动 |

## P3：覆盖与效率

| 项目 | 当前判断 |
| --- | --- |
| 儿童 BodyFit | 需要独立比例、资产和伦理/数据规范，不继承成人池 |
| 更多身高档位 | 暂不使用整体缩放；需验证骨骼、步幅和环境交互 |
| 自动弹窗点击扩展 | 只接受标题、进程、控件和状态精确匹配，不做通用自动点击 |
| CC 批次节流自适应 | 可根据内存、加载时间和弹窗频率调整间隔 |
| 自动视觉异常检测 | 可先做眼球/肤色接缝/空白截图检测，仍保留人工审核 |
| 资产重复与近似聚类 | 头发和服装数量扩大后再做，不阻塞当前验证 |
| 自动生成 MRQ 数据集 | 依赖阶段 10 的统一角色接口和场景规范 |
