# ADR-0014：按兼容域构建配置图并采用双策略编辑链

## 1. 背景

首批资产已经形成每性别 `4 identity × 4 outfit` 的完整 Look 矩阵，并冻结每性别 5 个动作和四台相机。男女角色不共享身份、动作和服装，因此把全部节点强行连接成单一图没有语义依据。

多轮编辑还需要同时覆盖两类行为：一类是每次推进一个新轴、没有回退的最短编辑；另一类允许反复修改、连续编辑同一轴、回退和闭环。旧版 `progressive/rollback/closed_cycle` 三分类把生成策略与结果特征混在一起，难以准确表达一条链的真实结构。

未来正式生产的笛卡尔积会很大，不能永久依赖先渲染所有可能节点；但首批只有 640 个节点，完整物化能降低调度和重采样风险。

## 2. 决定

### 2.1 兼容域

- 首批建立 `female_v1` 和 `male_v1` 两个兼容域，各 320 节点。
- 每个域内部必须连通；不要求两个域组成全局连通分量。
- 禁止跨域边和跨域链。
- 未来骨架、服装或其他硬兼容条件变化时，用新域表达，不用特殊捷径连接不兼容状态。

### 2.2 原子编辑

首批只开放：

- `E1 identity`；
- `E2 outfit`；
- `E3 action`；
- `E7 camera`。

每条边恰好改变一个轴。表情固定为 Happy，不开放 `E11`。

### 2.3 链策略

只保留两种 `chain_policy`：

- `progressive_shortest`：每个轴最多一次，无重复节点、无回退，链长等于起终状态语义 Hamming 距离；
- `freeform_walk`：允许重复轴、连续同轴、重复节点/边、回退和返回起点，也允许偶然得到最短链。

每条链另外保存五个由路径重算的事实标签：

```text
is_semantic_shortest
has_repeated_axis
has_consecutive_same_axis
has_rollback
returns_to_start
```

首批 4,000 条链按两个策略 50/50、男女域 50/50 分配，精确长度配额由采样规范负责。

### 2.4 连通与距离

- 交付链的每一步必须是登记过的原子边。
- 每个兼容域必须连通。
- 不要求任意两个渲染节点之间的图距离都等于语义特征差异数。
- 不要求所有可能的最短边链都存在。

这使稀疏生产可以用少量桥接节点保证可达性，而不用为全点对等距付出接近完整笛卡尔积的成本。

### 2.5 节点生产模式

- 首批采用 `full_pool`：生成链并完成图门禁后，渲染完整 640 节点。
- 后续正式生产采用 `referenced_nodes_plus_connectivity`：只渲染所有链引用节点的并集，加上维持每个兼容域连通所需的桥接节点。
- 同一节点视频只渲染一次，由多条链复用。

## 3. 后果

- 男女数据可以分别形成严格连通、可验证的图，不制造无意义跨性别身份边。
- 链的“生成方法”和“最终结构事实”分离，统计与训练筛选更可靠。
- 首批节点预算从旧的多表情/双镜头解释收口为四镜头/Happy-only 的 640 节点。
- 表情仍可用于角色自然度，但首批不作为编辑轴；未来重新开放时需要新 schema/manifest 版本。
- 后续可在不重渲染节点的情况下调整链策略比例或重采样语言指令。
- 当前配置图生成器必须迁移；旧输出只能作为历史测试，不能标记为本决定下的正式数据。

## 4. 未采用方案

| 方案 | 原因 |
| --- | --- |
| 男女节点构成单一全局连通图 | 缺少合法跨域资产与动作语义，会引入伪边 |
| 要求任意节点对的图距离都等于 Hamming 距离 | 对稀疏图成本过高，且不是链样本成立的必要条件 |
| 保留 `progressive/rollback/closed_cycle` 三分类 | 混淆采样策略与链的事实特征，闭环和回退存在重叠 |
| 所有链禁止连续编辑同一轴 | 排除了用户明确需要的现实反复修改行为 |
| 正式生产永久渲染完整笛卡尔积 | 扩展后计算与存储成本不可控 |
| 首批立即使用稀疏节点池 | 640 节点规模可控，全量池更利于验收、重采样和故障定位 |

## 5. 复审条件

出现以下任一情况时新增 ADR 取代本决定，不静默改写：

- 表情正式成为可编辑轴；
- 身份、服装或动作实现可靠跨域转换；
- 数据训练明确要求全局单连通或全点对等距；
- 链长度超出 3–5 或新增组合编辑边；
- 稀疏生产证明仅靠桥接节点无法满足质量或采样覆盖要求。
