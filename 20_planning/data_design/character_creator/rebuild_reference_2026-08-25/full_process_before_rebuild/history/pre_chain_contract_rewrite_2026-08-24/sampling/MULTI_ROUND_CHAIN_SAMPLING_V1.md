## 1. 采样目标

默认生成 4,000 条链；服务器或节点降级不减少链目标，只提高合法节点复用率。最小交付为 3,000 条完整有效链。

| 链长度 | 默认数量 |
| ---: | ---: |
| 3 次编辑 | 1,000 |
| 4 次编辑 | 2,000 |
| 5 次编辑 | 1,000 |

## 2. 原子边

采样器只能使用通过 schema 验证的 `E1/E2/E3/E7/E11` 有向边。每一步只能改变一个轴：

- `E1`：身份。
- `E2`：服装。
- `E3`：身体动作。
- `E7`：相机。
- `E11`：表情。

不允许采样器通过直接修改 node JSON 绕过边注册表。

## 3. 允许的重复与回退

- 允许连续编辑同一轴，例如先换衣服，再换回原衣服。
- 允许重复访问之前的任意节点。
- 允许最后回到起点。
- 回退必须走真实反向边，并复用原 node_id 和媒体。
- 同一条链中重复同一有向边原则上最多一次；闭环需要时可显式放宽并登记原因。
- 禁止 `A→A`、伪编辑和只改变文本不改变配置的步骤。

## 4. 链类别

| 类别 | 默认比例 | 定义 |
| --- | ---: | --- |
| `progressive` | 70% | 不回到已访问节点，但可以重复编辑轴 |
| `rollback` | 20% | 至少一次返回历史值或历史节点，末节点不强制等于起点 |
| `closed_cycle` | 10% | 末节点等于起点，至少两条不同有向边 |

比例允许在最终 4,000 条上有 `±2%` 偏差。若图降级后无法满足，必须在报告中显式记录实际比例，不能静默改类。

## 5. 编辑轴覆盖

全体链至少满足：

- 五个编辑轴均出现。
- 每个轴至少占总边数的 10%。
- `E1` 与 `E2` 各至少占 15%，保证核心身份/服装 pair 数量。
- `E7` 只发生于 Happy 的 medium/full-body 节点之间。
- `E11` 只发生于 medium 的 Happy/Angry/Sad 节点之间。
- 不强制每条链覆盖所有轴；避免机械固定模板。

每个身份、服装、动作、表情和相机都必须在起点、终点或中间节点中达到最低覆盖，精确阈值由节点图生成后按可用度均衡计算。

## 6. 路径生成

采样使用确定性随机种子。建议流程：

1. 按目标链长度和类别建立配额。
2. 从满足性别/身份/服装覆盖欠额的节点加权选择起点。
3. 在当前节点合法出边中，按编辑轴欠额、目标类别和近期路径历史加权选择。
4. rollback/closed-cycle 预留足够剩余步数，确保存在返回路径。
5. 完成后执行整链 schema、原子性、类别和引用验证。
6. 用规范化有序路径计算 chain_id；重复则继续采样。

禁止先生成文本再反推配置。配置路径是权威，指令文本从已冻结边和链历史生成。

## 7. 指令生成

每条边至少有一条清晰指令，指令只描述该边的变化。回退指令应区分：

- 直接指值：如“换回 O1 对应的服装”。
- 历史指代：如“换回第一轮的服装”。
- 相对表达：如“恢复之前的中近景镜头”。

历史指代必须能由 chain JSON 唯一解析；存在两个同名历史值时改用轮次或显式值。不得在一句指令中附带未发生的身份、动作、镜头或表情变化。

## 8. 去重

两条链只有在以下全部相同才视为重复：

- 起始 node_id。
- 有序 edge_id 列表。
- sampler_version 和语义策略版本。

仅最终节点相同不构成重复。反向路径也不等于原路径。文本表面不同但配置路径相同，默认仍视为同一数据链；文本改写可作为独立语言增强层，不增加配置链计数。

## 9. 质量报告

采样完成后至少报告：

- 总链数、长度分布和类别分布。
- 五个编辑轴的边计数。
- 身份、服装、动作、表情、相机覆盖。
- 唯一节点使用数、节点复用率和最大单节点入度。
- 回退链、闭环链、重复路径、无效边和悬空引用数量。
- 指令模板使用分布和历史指代数量。

硬失败条件：有效链少于 3,000、任一无效边、任一悬空引用、任一伪编辑、同 chain_id 对应不同路径或同 node_id 对应不同配置。

## 10. 与渲染的边界

采样器不启动 UE，也不决定哪些节点重渲染。它只引用 `nodes.jsonl` 中已定义节点。渲染器只消费唯一 node_id；链生成先后不影响媒体内容。

首个 100 链 dry-run 通过后再生成完整 4,000 条。正式实现和验证命令在代码完成后登记到 `WF-09` 与 Validation Catalog，本文件不提前声明实现已存在。
