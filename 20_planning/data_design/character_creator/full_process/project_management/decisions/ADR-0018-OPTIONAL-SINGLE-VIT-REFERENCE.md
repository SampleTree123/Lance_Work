# ADR-0018：Lance 每轮可选单张 ViT 参考图

> 文档 ID：`ADR-0018`
> 文档类型：`decision`
> 生命周期：`compatibility`
> 状态：`accepted`
> 决定日期：2026-10-11
> 影响范围：Lance 下游训练/推理输入、条件角色与实验准备；不改变 WF-90 发布合同
> 最近核验：2026-10-11

> 2026-10-22：未来输入范围由[ADR-0020](ADR-0020-VAE-MULTI-REFERENCE-BRANCH-DIRECTION.md)取代；下列内容保留为当前旧版单图ViT实现合同，不限制新架构。

## 背景

文字难以完整指定服装等视觉属性，但相机视角等编辑仍适合仅用文字。用户决定先单独实现图片参考，再根据效果讨论分支编辑；当前阶段每轮最多一张，不加入多视角或动作参考视频。决定接受的是输入语义与工程范围，不是学习后质量结论。

## 决定

1. 保持直链和原有视频/文本路径。同一任务可包含有参考图和无参考图轮次；无图不补空白图、不插角色标记。
2. 图片只通过现有冻结 ViT 编码，作为所属 user 指令的参考条件；文字说明借用属性。源视频决定保留内容，参考图不得被选作最新源视频、目标视频或额外 loss 目标。
3. 每轮最多一个静态图片路径或 null。训练用与 prompts 对齐的 `reference_images`；推理用 user turn 的 `reference_image`。先前轮次参考保留在对应历史上下文，不自动改作当前指令的新参考。
4. 复用现有静态时间网格、video placeholder 和 UND token 路由，不新增随机词表 embedding；已有源/目标 VAE 与 flow-matching loss 不变。
5. 第一版沿用现有 ViT CFG，其条件包含历史视频和参考图。独立参考 CFG、参考图 VAE、动作视频、多视角以及分支关系不在实现范围。
6. 新参考图实验必须显式绑定含参考的监督数据、审计文件与路径哈希，创建独立 run/W&B 身份。现有无图训练集不得被标记为已支持参考监督。代码 hash 改变后不能把旧 adapter 加载成功视为严格恢复兼容。

## 影响与后果

- 复用现有主干与视觉编码器；增加的 token 仍有主干计算成本，是否提高编辑准确性必须训练后验证。
- 无图回归、参考不替代源/目标、训练推理一致性、条件 dropout、路径绑定与真实 GPU forward/backward 是工程验收条件。小尺寸 smoke 不替代正式规模、八卡恢复或视觉质量验收。
- 数据制作不属于本次实现；不从目标视频自动抽图制造隐式监督泄漏，不修改 released 数据。
- 实现、命令、脚本及诊断输出的唯一 Technical owner 为[训练接入](../../../../../../10_research/model_experiments/lance/training_integration.md)；详细证据见[参考图实现报告](../../../../../../10_research/model_experiments/lance/reports/datamake_optional_reference_image_20261011.md)。计划验收归 L11，WF-90 保持已关闭。

## 复审条件

当参考 ViT 已能稳定控制主要外观，但细节还原仍不足时，再评估参考 VAE/细节通路；当确有时序或多视角需求时，再扩展素材类型。分支编辑须在独立讨论中明确父节点、缓存与历史关系，不借本决定自动扩展执行范围。
