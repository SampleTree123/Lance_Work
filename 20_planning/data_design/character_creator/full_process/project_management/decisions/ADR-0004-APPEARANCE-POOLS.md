# ADR-0004：外观资产只从审核池选择

## 背景

本地资产数量大、显示索引不完整，并且不同资产的应用模式和弹窗选择不同。任意替换眼球对象会破坏已经匹配的几何与眼骨状态。

## 决定

皮肤、眼球、眉毛、睫毛、牙齿和胡须只从机器 registry 的审核池选择。眼球 12 项只按 `Material Only` 应用；牙齿等按登记策略 `Replace`。皮肤和眼球之后统一应用材质质量档案。

## 影响

- 资产数量受控且可追溯。
- 自动化必须识别应用模式，不能通用点击同一按钮。
- 新资产需先通过兼容矩阵和视觉门禁再加入池。
- API 成功仍不能替代闭眼、视线、微笑和张嘴检查。

## 复审条件

资产应用 API、几何兼容机制或运行时模块化边界发生变化，足以安全扩大组合域或取消现有应用模式区分时复审。
