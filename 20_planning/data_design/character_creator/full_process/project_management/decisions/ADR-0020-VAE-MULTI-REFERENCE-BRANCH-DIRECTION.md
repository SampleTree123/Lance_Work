# ADR-0020：多参考 VAE 与分支编辑的目标架构

> 文档 ID：`ADR-0020`
> 文档类型：`decision`
> 生命周期：`current`
> 状态：`accepted`
> 决定日期：2026-10-22
> 最近核验：2026-10-23
> 影响范围：Lance下一版输入与推理设计；接受需求方向，不代表代码实现或质量验收

## 背景

用户明确了按属性提供图片/视频的规则，并要求生成参考改走VAE，分支选择使用理解tool_call后再生成。旧ADR-0018的单张ViT参考只是已实现第一版，不再限定未来架构。

## 决定

1. 参考按属性组织：身份1张脸、发型同人正背2张、单件服装正背2张、整套服装全部部件与鞋的正背图、动作1段视频、场景1张空背景；发色/镜头及赤足说明可纯文本。详细保持/变化规则由[方案](../../../../../../10_research/model_experiments/lance/reports/datamake_vae_references_branch_plan_20261022.md)表格记录。用户准备数据。
2. 新生成参考使用VAE；可选无参考输入保留。多图/参考视频及其分辨率预算尚未实现，VAE不等同自动像素对齐或硬控制。
3. 理解先输出工具调用选择视频；程序解析真实parent，再按选中祖先路径生成。继续遵守ADR-0019的编号、默认-1、分开训练与推理失败回退语义。
4. 2026-10-23确认生成阶段优先保留压缩后的早期祖先ViT（H1）；具体采样、尺寸、参数隔离尚待讨论。完整保留/压缩/删除历史ViT登记为未来消融，目前不执行。
5. ADR-0018作为旧版实现合同保留兼容；未来范围由本决定取代其单图/仅ViT限制。现有训练代码与源锁不因文档更新而改变。

6. 2026-10-23用户确认：生成参考只作用于当前轮；训练/推理均不重复输入历史参考，不自动继承历史参考KV；历史素材/关联仅存档追溯。无参考轮次不回填旧参考；过去编辑通过选中源视频继承。历史视频ViT与文字政策独立于本条；ViT首选见第4条，历史prompt消融见第7条，本规则未实施。

7. 2026-10-23用户要求登记生成阶段历史prompt保留/移除对照；当前prompt始终保留，源视频、当前参考、历史ViT与路由保持一致。只记录实验计划，尚不判定历史prompt必然有益或有害，不执行实验。

## 影响与后果

新VAE参考需要角色、独立网格、注意力、CFG、target-only loss与训练推理一致性验证。完整会话存储与单次模型上下文分开；不能靠静默截断解决预算。单脸与单背景的信息不足必须在验收中体现。

Technical owner仍为[训练接入](../../../../../../10_research/model_experiments/lance/training_integration.md)。L09负责分支，新增L12负责VAE多参考与预算；旧L11工程证据保留。WF-90发布包和Gate不变，本轮不启动训练、不制作数据。

## 复审条件

待用户确认历史ViT压缩参数、身份身体目标、最大媒体数量/时长和候选数，再冻结实施配置；质量和资源需实验验收，不能由该决定自动晋升。
