> 权威范围：已完成计划、里程碑和整理后的历史报告

- [里程碑](./MILESTONE_LOG.md)：按时间记录已经发生且仍有解释价值的主要结果。
- [已完成计划](./completed_plans/README.md)：从活跃计划移出的完成项。
- [报告](./reports/README.md)：面向汇报的时间段快照。

历史只证明过去发生过什么，不决定当前执行。当前事实见 [项目状态](../status/PROJECT_STATUS.md)。重构前原文和重复历史完整保存在 `rebuild_reference_2026-08-25` 快照中，不复制进活跃树。

## 历史记录契约

- 里程碑只记录已发生并具有长期解释价值的结果，不记录“准备做”或当前下一步。
- 完成计划必须保留目标、最终需求状态、接受证据、未纳入范围和关闭日期；迁入后原则上只做事实纠错，不随当前实现滚动改写。
- 报告是时间段快照，其中计数和路径只在报告日期有效；读者必须回到 Status 获取当前事实。
- 被新架构取代的原文保存在树外哈希快照，不从活动 Master 建立执行链接，也不作为当前权威。
