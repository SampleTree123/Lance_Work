# study —— 学习笔记与概念沉淀

> 父层：[`../README.md`](../README.md)。

本目录用于存放学习路线、论文阅读笔记、模型架构概念、代码走读记录和后续讨论沉淀。这里不放模型权重、运行输出、日志或大文件。

## 内容说明

| 文件/目录 | 内容 | 状态 |
|-----------|------|------|
| `README.md` | 本层索引和归档规则 | 当前 |
| `multimodal_model_learning_plan.md` | Lance 起步的统一多模态视频模型学习路线 | 当前 |
| `lance.md` | Lance 项目与论文阅读笔记 | 初读 |
| `bagel.md` | BAGEL 来源登记与后续阅读入口 | 已登记 |
| `pdfs/` | 本地论文 PDF 缓存 | 忽略，不进 Git |

## 归档规则

- 论文、架构、MoT/CoT/PE/TTS、interleave、多模态模型概念等学习内容放在这里。
- Lance 环境、脚本运行、显存、输出结果和失败案例放在 [`../model_experiments/`](../model_experiments/README.md)。
- 如果学习结论影响 DataMake 数据方案，再同步到 [`../../20_planning/`](../../20_planning/README.md) 或 [`../../00_engine/`](../../00_engine/README.md)。
- 讨论中还不稳定的想法可以先不写；稳定后再整理成独立笔记。
