# 10_sources —— 数据来源工作区（Level 1）

---

## 📂 内容说明

| 子目录 | 内容 | 状态 |
|--------|------|------|
| `real_video/` | 来源①：真实视频数据集筛选、清洗、标注、许可 | 待展开 |
| `model_generated/` | 来源②：大模型生成视频/图片/编辑数据 | 待展开 |
| `unreal_engine/` | 来源③：Unreal Engine 合成视频数据 | 当前主攻 |

## 数据来源定位

- `real_video/`：提供真实分布和画质锚点。
- `model_generated/`：补内容和题材多样性，尤其是引擎内不方便覆盖的域。
- `unreal_engine/`：提供精确可控、可配对、可端点复用的编辑监督，是当前核心来源。

## Agent 备忘（10_sources）

- 不要把真实数据集、模型生成输出或 UE 渲染成品提交进 Git。
- 任何来源产生的数据都要最终对齐到 `20_dataset/` 的统一 schema。
